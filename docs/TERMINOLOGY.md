# MADMAN Terminology

MADMAN uses theatrical names so that the code does not quietly smuggle conventional cognitive modules back into the architecture. The names are intentionally memorable and slightly absurd. Each still has a strict operational meaning.

**MADMAN** means Metaphysical Artificial Dynamics for Metabolic Autopoiesis and Noesis. It replaces the earlier PEMA working name for the radical branch of the experiment.

**Crucible** means the complete artificial substrate and its local physical laws. It is not an agent.

**Spark** means a transient local occurrence. It is the implementation analogue of an occasion or event, not a thought object.

**Aether** means free resource that can immediately pay for local transformation and propagation.

**Ichor** means bound local reserve created from Aether under sustained activation and later released locally.

**Azoth** means resource capable of paying for structural plasticity. Quiet regions can slowly recover it by converting Aether.

**Ash** means inhibitory residue created by activity. It increases local cost and reduces conductivity until it dissipates.

**Scar** means durable deformation of an edge caused by repeated coactivation. It is the main substrate for reconstruction history.

**Echo** means an observer's description of a previous organization becoming partially reconstructed because history changed the substrate. There is no Echo object in the core physics.

**Haunting** means an observer's description of a recurrent configuration that repeatedly captures enough resource to rebuild itself. There is no Haunting class in the core physics.

**Morrow** means the locally propagated field created by possible future resource availability. It biases present propagation without representing an explicit goal.

**Constellation** means an observer-detected temporary cluster whose members are strongly active and mutually coupled. The substrate does not know that a Constellation exists.

**Veil** means the causal separation between local structures. `VeilChannel` uses the name for communication that transports perturbations rather than shared state.

**Glyph** means an external perturbation emitted by one local surface and received, after stable distortion, by another substrate.

**Medium** means the intentionally disadvantaged verbal reporter. It sees only designated report surfaces and cannot inspect the hidden machinery responsible for them.

**GhostHunter** means omniscient researcher instrumentation. It may inspect the Crucible, but the Crucible may not inspect it.
