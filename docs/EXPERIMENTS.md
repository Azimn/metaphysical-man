# MADMAN Experiment Battery

The initial battery is intentionally broad. It exists to find places where the monster twitches. These experiments are not presented as proof of cognition or consciousness. They are smoke tests for the more specific claim that local metabolic laws can create behavior that resembles familiar cognitive phenomena without directly encoding those phenomena as modules.

## Echo

The Echo experiment repeatedly perturbs a local region with the same signature, allowing coactivation to produce Scars and Ichor. After active state decays, a weaker partial cue is introduced. The experiment measures whether the trained substrate produces stronger later activation and whether spontaneous reconstruction events occur. No stored memory record is consulted by the runtime.

## History

The History experiment begins from identical Crucibles. One receives repeated experience while the other does not. After a settling period, both receive the same probe. A response difference demonstrates path dependence. The important result is not that one branch has a larger number. The important result is that the difference can be traced to physical changes produced by prior experience rather than to a hidden history label.

## Haunting

The Haunting experiment deliberately strengthens a recurrent local pattern and then removes the external driver. The observer watches whether reconstruction continues for a time and whether it eventually collapses as resource and Ash dynamics change. A persistent loop is allowed. A loop that never terminates is also informative.

## Attention

The Attention experiment introduces competing streams into a resource-limited substrate. There is no attention controller. GhostHunter measures whether one site or cluster captures a disproportionate share of metabolically supported activation and how concentrated the resulting flow becomes.

## Fork

The Fork experiment clones one substrate into two lineages. The branches receive different histories and later encounter the same probe. Divergence in activation and Scars measures whether the initially identical systems have become different dynamical individuals.

## Morrow

The Morrow experiment allows the prospective field to relax around resource sources. The result checks that a future-resource gradient exists before using it in more complex behavior. The next generation of this experiment should compare otherwise identical Crucibles with Morrow enabled and disabled, then ask whether Morrow changes the trajectories that survive under scarcity.

## Speech

The Speech experiment creates a hidden structural cause and asks the Medium for a report. The report should reflect only the report surfaces. It should never expose Aether, Ichor, Azoth, Ash, Scars, topology, source placement, or trace metadata. The intended phenomenon is a real gap between causal explanation and verbal self-report.

## What happens after an interesting result

An interesting outcome should trigger reduction rather than immediate expansion. The phenomenon should be reproduced across seeds, compared to a simpler substrate, ablated one mechanism at a time, and evaluated against a null system with equivalent computational budget. Only after that should the project claim that a particular MADMAN mechanism contributes something distinctive.
